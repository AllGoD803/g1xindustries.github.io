Votre première soumission

  1. Dupliquez l’exemple ou créez un projet. Nommez le travail et le client.
  2. Ajoutez les matériaux et leur coût unitaire, puis les heures et leur coût interne.
  3. Ajoutez la sous-traitance, les frais d’atelier et une réserve d’imprévus.
  4. Choisissez la marge souhaitée, puis configurez l’identité de votre atelier et les taxes.
  5. Ouvrez l’aperçu client, relisez-le et choisissez « Imprimer / PDF ».

Sur votre iPhone

Ouvrez la version en ligne dans Safari. Vous pouvez utiliser Partager → Sur l’écran d’accueil pour créer un raccourci.

Pour un PDF, ouvrez la soumission, touchez « Imprimer / PDF », puis utilisez les options de partage de l’aperçu d’impression.

Ce site n’est pas une application native et ne synchronise pas les appareils. La version HTML téléchargée est surtout destinée à un ordinateur; l’ouverture de fichiers HTML dépend du navigateur utilisé.

Sauvegarder et retrouver

Les projets sont enregistrés dans le navigateur de cet appareil. Effacer les données du navigateur peut les supprimer. L’export JSON est votre copie transférable.

L’import ajoute les projets à votre liste avec de nouveaux identifiants. Il ne remplace pas les projets existants. Limite : 100 projets au total, fichier de 2 Mo maximum.

Comprendre les chiffres

Coût prévu = matériaux + travail + sous-traitance + frais d’atelier + réserve.

Prix avant taxes = coût prévu ÷ (1 − marge cible).

Marge en dollars = prix avant taxes − coût prévu. Ce montant n’est pas automatiquement le bénéfice net de l’entreprise.

Coût réel = toutes les dépenses effectivement affectées au projet, saisies après réalisation. La comparaison utilise le prix actuellement enregistré; dupliquez un projet avant de réviser une offre déjà envoyée.

Ce que couvre cette version

Calculs en dollars canadiens, montants arrondis au cent sur chaque ligne, projets locaux, import/export, version HTML et document imprimable. Les deux taxes portent sur le même prix avant taxes.

Cette première version ne gère pas la facturation, les paiements, les stocks, la signature, les comptes multiutilisateurs, la synchronisation ou les exigences techniques d’un ouvrage. Les heures et les coûts sont fournis par l’atelier.

Aucun service d’IA ni traceur publicitaire n’est intégré à l’outil. Les saisies ne sont pas transmises à un serveur par l’application. L’hébergeur assure l’accès au site.
